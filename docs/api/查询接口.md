# 查询接口契约

更新：2026-11-04。此文档描述实际实现，规划接口在交接文档单独标记。

## POST /api/query_range

`Content-Type: application/json`，最大 16 KiB：

```json
{"namespace":"pts","env":"test","app":"","levels":[],"keyword":"timeout || failed","traceId":"","spanId":"","parentSpanId":"","taskId":"","messageId":"","start":1793635200,"end":1793721540,"direction":"BACKWARD"}
```

| 字段 | 含义 |
|---|---|
| namespace | 配置的平台；未传时使用第一项；无平台配置时只能为空 |
| env / app | 环境、应用；至少提供 env、app 或有效 levels 中的一种 |
| levels | debug/info/warn/error 数组，空表示不限级别；大小写兼容 |
| keyword | `&&` 为 AND，`\|\|` 为 OR，混合按字面短语 |
| traceId / spanId / parentSpanId / taskId / messageId | 可选关联字段，非空条件按 AND 组合 |
| start / end | Unix **秒**整数，均大于 0，end 必须晚于 start |
| direction | 仅 FORWARD 为正序，其余按 BACKWARD |
| cursor | 原样传回上一页 nextCursor |
| limit | 可选整数，1–1000；未传或 null 时使用存储配置 default_limit |

每页最多返回条数优先使用请求 limit，未传时使用存储配置 default_limit（1–1000）。limit 为 0、负数、超过 1000、非整数或字符串均返回 400；实际返回可能少于该值。翻页时保持 limit，游标生成使用本次实际 limit。共享查询服务负责参数、分页及结果整理；LogQL/DSL 在存储实现内生成。

成功响应直接返回结果，无 data 包装：

```json
{"lines":[{"ts":"2026-11-03T10:30:00+08:00","level":"error","line":"message failed","labels":{"env":"test","app":"worker","traceId":"abc"},"index":"app-log-pts-test-20261103","id":"document-id"}],"total":1,"nextCursor":"<opaque cursor>"}
```

index/id 可缺失。total 为本页日志数，不是全量命中数。nextCursor 缺失表示没有可继续的游标。

标签白名单：env、app、level、tid、traceId、namespace、spanId、parentSpanId、taskId、messageId、sequence、logger_name、thread_name、host。

## 分页和错误

- ES 的 `es1:` 游标绑定条件、原时间范围和方向，包含 PIT 与精确排序值；翻页保持原条件，不自行修改或解析游标。按 `@timestamp`、`sequence`、`_shard_doc` 排序，兼容缺少 sequence。
- PIT 每页续期 2 分钟，结束时关闭，放弃后自动过期；失效返回 404，重新查询第一页。
- Loki 和旧数字游标是 Unix **纳秒**字符串；正序 start=cursor+1ns，倒序 end=cursor−1ns。无剩余范围返回 400，不用 JavaScript Number 处理纳秒游标。
- 时间戳分页在同一时间戳超过一页时有漏行限制；ES PIT 支持稳定翻页。

| 状态 | 情况 |
|---|---|
| 400 | JSON、范围、平台、筛选或游标不合法 |
| 413 | 超过 16 KiB |
| 上游相同 4xx | 存储返回非成功 4xx，包含快照失效 |
| 502 | 网络、超时、上游 5xx、ES timed_out/分片失败或响应处理失败 |

错误体：`{"error":"说明"}`。平台配置并不等同于用户身份认证，仍沿用部署的内网访问控制。

## 页面查询链接

`/` 的 URL 支持 `namespace/env/app/levels/direction/keyword/trace_id/span_id/parent_span_id/task_id/message_id/start/end/limit`。levels 逗号分隔；关联字段 API 用 camelCase，链接用 snake_case。统一使用 `web/static/js/share.js` 编解码。

链接不包含游标，打开自动重查第一页。

## Agent 与 MCP

`GET /api/query_options` 返回公开 UI 选项（Namespaces、Envs、Apps），不包含模型或 MCP 密钥。外部 Agent 可使用带 Bearer 认证的 `/mcp` 调用 get_query_options 与 query_logs，详见 [MCP 接入](../integrations/MCP接入.md)。
