# 日志查询使用手册

更新：2026-11-04。访问地址、平台、环境和应用以部署配置为准。

## 日志查询

首次进入使用第一项环境、全部级别、倒序和今天 00:00–23:59。浏览器记住平台、环境、级别和方向。

查询条件分四行：

1. 应用和时间；应用“不限”表示不限制应用。
2. 链路id（TraceId）、线程任务id（TaskId）、MQ消息id（MessageId）。
3. 关键词、查询、双箭头展开控件。
4. SpanId、ParentSpanId，默认折叠，收起保留已填值。

时间必填；`1h` / `3h` 从相应小时前整点开始，结束仍为今天 23:59；`今天` 为当天 00:00–23:59。关联 ID 精确匹配，多项按 AND 组合。关键词 `a && b` 同时包含，`a || b` 任意包含，混合则按一段字面文本查询。

## 结果、图表与分享

- 日志按东八区显示时间，标签颜色按 key 稳定分配，正文作为文本显示。
- 图表按分钟、级别统计**已加载的日志**，不是全量统计。零值柱不显示，非零小值至少显示 3px；悬浮查看真实数量。
- 滚动到底部继续加载，“已加载 N 行”与 API `total` 都不是全量命中数。
- ES 按时间、sequence、`_shard_doc` 排序，PIT 每页续期 2 分钟；失效后重新查询。查询后新增日志需新建查询才能看到。
- sequence 仅代表同一进程本次运行的事件顺序，不能跨服务、实例或重启推断因果。
- 点击 `tid` / `traceId` 在新页打开关联日志：保留当前平台、环境和时间，清空应用、级别、关键词及其他关联筛选。第一页不代表完整链路。
- 其他标签点击复制；超过 10 行的日志可展开。
- 右上角分享按钮复制当前查询链接；打开后恢复条件并自动查询。
- 齿轮内切换主题、调整 90%–150% 字号，100% 为默认。
